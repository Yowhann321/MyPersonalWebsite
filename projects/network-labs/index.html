      About this viewer

      Packet Tracer saves labs in an encrypted format. I decoded my two files and turned the devices, links, configurations and command history into this page. Passwords are hidden.

      The ping tracer follows each frame through switch ports and VLANs, picks the gateway from the DHCP pool, and routes using the RIP networks each router advertises. PC addresses are example DHCP leases, because Packet Tracer doesn't save them; the gateway each PC received is saved, and it matches.
