  • Tap + to log an expense, income, or transfer, and watch the dashboard update.
  • Try the calculator. It uses the same formulas as the app's Kotlin code.

What the app does

  • Account login and registration with token-based sessions
  • Monthly calendar that marks expense, income, and mixed days
  • Logs expenses, income, and transfers between accounts, with filters and per-day grouping
  • Simple interest, compound interest, and loan calculators
  • Stock watchlist with live quotes, search, and auto-refresh every 60 seconds

How it's built

  • Kotlin, Android SDK 24+, XML layouts, and Material Components
  • Single activity with fragments and the Navigation component
  • OkHttp talking to a PHP REST API (login, dashboard, transactions)
  • Finnhub API for market data; watchlist saved on the device

About this demo

The real app needs its PHP backend, so this page recreates its screens in HTML and JavaScript using the app's own colors, layouts, and logic. The data is sample data and is saved only in your browser.

The Accounts tab shows "coming soon" because it isn't finished in the app yet either.
