IT129 · Cryptography project

Cipher Lab / Flskhu Ode

Four classical ciphers I wrote in Python, including one I designed myself. They're ported here so you can try them in the browser. Type a message, encrypt it, and see each step of the math.

  • Python
  • Cryptography
  • Algorithms
  • JavaScript port

Where it started

The original is a Python console app. Main_Prog.py has a CipherManager class with a menu that describes each cipher and launches it. Each cipher builds its key, takes your input, and prints the steps of the process.

Bringing it to the web

Each algorithm was ported to JavaScript line for line, so the page loads instantly and needs no Python runtime. The rules are the same: letter case is preserved, symbols pass through, and keys are reshuffled on every load. My original Python is under each cipher.

A note on security

These are classical ciphers for learning. Frequency analysis breaks the substitution ciphers, and a repeating key weakens Vernam. Modern systems use ciphers like AES instead.
