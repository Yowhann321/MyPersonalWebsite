# Johann Lijauco · Portfolio

Live at https://yowhann321.github.io/MyPersonalWebsite/

- `index.html`: home page with selected work, capabilities, and contact
- `work.html`: project and writing detail pages, rendered from `data.json`
- `writing.html`: poems, filterable by haiku and narrative
- `projects/cipher-lab/`: interactive demo of my cryptography course project

To add a project, add an entry to the `projects` array in `data.json`.
Every push to `main` deploys to GitHub Pages.
